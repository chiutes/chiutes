# chiutes

A lightweight project workspace for experimentation, scripts, and utilities.

## Overview

This repository is currently set up as a minimal starter project. It is intended to hold code, notes, and supporting files for ongoing work.

## Structure

- `README.md` — project overview and usage notes

## Getting started

1. Open the project in VS Code.
2. Create or add your Python scripts, notebooks, or other project files in the workspace.
3. Use a virtual environment if needed for dependency isolation.

## Example setup

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
```
